FINORA — мобильный менеджер финансов (прототип)
=============================================
Файлы:
- index.html — приложение
- manifest.json — параметры установки на главный экран
- sw.js — кеширование для офлайн-запуска

Быстрый запуск:
1. Распакуй архив.
2. Открой index.html в браузере для тестирования. Некоторые браузеры не включают установку PWA при открытии локального файла.
3. Для установки на главный экран опубликуй папку на HTTPS-хостинге (например, GitHub Pages) и открой ссылку в Chrome на Android.
4. В Chrome нажми меню ⋮ → «Добавить на главный экран» или «Установить приложение».

Важно:
Это веб-приложение (PWA), а не APK. В этой среде Android SDK не настроен, поэтому APK не собран.
Транзакции и подписки пока ведутся вручную. Для реального импорта операций с банков/платформ нужны официальные API, авторизация и серверная часть.
Данные хранятся локально в браузере. Не вводи банковские пароли или данные карт.
